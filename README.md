# Research Studio 規格書

## 1. 目標
- 可在瀏覽器第一人稱走進去的 3D 研究室，1～3 人使用的 NLP 研究空間
- 風格：寫實、溫馨、日系光影（斜射陽光、木地板光影），不要卡通/迷你模型感
- 實用：房間裡的物件能真的拿來管理研究工作（待辦、截止日、專注計時）
- 公開在 GitHub Pages，網址打開就能用

## 2. 場景（Blender 建模）
- 真實尺度，近距離看也要有細節
- 配置：2 個主要工作位 + 1 個不擋路的彈性座位
- 動線：入口 → 工作桌 → 窗邊 → 露台走得通，椅子後方留後退空間
- 物件：
  - 27 吋 16:9 螢幕 ×2（支架、底座、線材、研究畫面）
  - 筆電、鍵盤（正常錯列鍵帽）、文具
  - 書架、落地燈、窗邊休閒椅（朝向窗景）+ 小邊桌
  - 牆上預留一面大木框板子，之後放儀表板，不能破壞溫馨感
  - 落地推拉門 + 露台，地板與室內接平、沒有門檻
- 窗外：
  - 山海：法羅群島風格的沉水海岸地形，要是真的 3D，換角度看不能穿幫
  - 都市夜景：遠近層次的樓群和窗燈
  - 兩種可切換
- 製作：Blender 建模 → glTF → three.js 即時渲染

## 3. 互動功能
### 3.1 房間
- 窗外 5 個時段：清晨 / 正午 / 夕陽 / 藍調 / 破曉前，光線、天空、描述文字一起變
- 開關：燈光、窗簾、筆電、露台門（點 3D 物件或面板按鈕）
- 視角：第一人稱（WASD、滑鼠環顧、E 互動、Esc 釋放）/ 平面全景
- 碰撞：不能穿牆、穿家具

### 3.2 研究白板（用 2 的大木框板）
- 點白板或按 E 打開面板
- TODAY：待辦新增 / 勾選 / 刪除 / 清除已完成
- DEADLINES：名稱 + 時間，倒數 X 天 Y 小時，依剩餘時間排序；<3 天強調、過期變灰
- READING：論文清單，依分類標籤篩選
- 資料存 localStorage
- 牆上 3D 白板即時顯示未完成數、最近截止日

### 3.3 專注模式（番茄鐘）
- 點筆電打開
- 25/5、50/10、自訂；開始 / 暫停 / 重設
- 專注：開燈、窗簾半拉、房間變暗；休息：窗簾打開
- 筆電螢幕顯示倒數，階段結束提示音
- 關掉面板後有倒數小膠囊，點了再打開
- 記錄今日完成次數，跨日歸零

### 3.4 其他
- 坐下：點椅子，鏡頭移到座位看桌上螢幕
- 手機：預設平面全景，操作提示依裝置顯示

## 4. 介面
- 首頁卡片：標語 +「走進研究室」，顯示載入百分比
- 左下：窗外時間卡片
- 右下：「讓房間回應你」控制面板
- 頁尾：操作提示、素材來源
- 色系：米白、木色、墨綠

## 5. 部署
- 單一 index.html（CSS/JS inline），模型貼圖放 assets/，全部相對路徑
- 單檔 < 50 MB，素材總量盡量壓小，首屏 < 25 MB
- 載入失敗要顯示錯誤，不能卡住或白畫面
- 素材只用免費資源，頁尾附授權署名

## 6. 不做
- 不接後端、不登入
- 不放真實個人資料（白板、螢幕用假資料）
- 不放 Blender 原始檔

## 7. 驗收
- 所有時段、景色、開關、視角可切換
- 白板資料重新整理後還在
- 番茄鐘計時、階段切換、燈光窗簾連動正常
- 手機寬度可操作
- Pages 網址打開無 error、無 404
